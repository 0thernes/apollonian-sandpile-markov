# Threat Model (`docs/threat-model.md`, v2.1.0)

| Threat Vector | Concrete Risk | Mitigation Implemented |
| :--- | :--- | :--- |
| **Hidden Lean axioms / `sorry` / `native_decide` / `@[extern]`** | Soundness collapse or unverified compiler trust | Zero `sorry`/`admit`/`native_decide`/custom `axiom`/`implemented_by`/`@[extern` in built modules (`lean/PalomarChallenge.lean` holds 17 intentional comparator stubs) audited by `VerifyAxioms.lean` (19 exports), exhaustive `VerifyAllDecls.lean` (all 818 `ApollonianSandpileMarkov.*` declarations via `Lean.collectAxioms`), `scripts/check_readme_axioms.py` (strict allowlist parser), `scripts/audit_repo.py`, `nanoda_bin` (`unpermitted_axiom_hard_error: true`), and a live CI negative rejection gate. |
| **Vacuous theorem statements / specification gaming** | Proving trivially true implications or weakened statements | Explicit `NonVacuity.lean` witnesses across all pillars (including all three HKRS roots, `lapZ2 uZ2_lap3a ≤ 3`, `T2d` bundle, stabilizing odometers, Cohn seed dets), `Adversarial.lean` refutations of 9 false/dropped-hypothesis variants (`adv1`–`adv9`, including `T2d` mean-equation and `T2a` `LegalTrace` necessity), `docs/statement-fidelity.md`, `lake check --paranoid`, and `lake comparator --paranoid` against `PalomarChallenge.lean`. |
| **Single proof-checker kernel bug** | Soundness bug in one Lean implementation | CI replay with `leanchecker --fresh` and `lean4lean` (modules `Solution`, `PalomarSolution`) and with `nanoda_bin`, `con-leche`, `con-ron` (export of three root declarations and their dependency closure), plus `lake comparator --paranoid` on all 17 comparator targets and a live negative kernel rejection gate. |
| **Memory corruption / UB in native code** | Silent arithmetic overflow or buffer error in C11/Rust | Zero `unsafe` in Rust (`#![forbid(unsafe_code)]`, `i128` exact arithmetic, total `exact_det_bareiss` with squareness check); ISO C11 compiled with `-std=c11 -Wall -Wextra -Werror -fsanitize=address,undefined` plus 100k 7-law deterministic fuzzer (`native/fuzz_asm.c`) and 7-law coverage-guided `libFuzzer` (`native/fuzz_libfuzzer.c`). |
| **Weak test suite / silent regressions** | Bugs slipping past unit tests | 600+ Hypothesis property tests, strict negative input & CLI validation, exact Rust $\leftrightarrow$ Python differential test, `< 1e-14` 3D Soddy geometry test, and 10 of 10 (100.0%) semantic mutants killed (`scripts/mutate.py`). |
| **Citation fabrication / retraction / artifact tampering** | Fake or wrong-paper DOIs, retracted refs, drifted PDFs, or altered binaries | 23/23 live Crossref/arXiv citation audit (`scripts/check_citations.py`, verifying `update-to` AND `updated-by` retractions plus title/author surname match), clickable PDF DOIs (`plainurl`), deterministic `mtime=0` arXiv tarball, LF-normalized `MANIFEST.sha256` / `SHA256SUMS` / `data/MANIFEST.sha256`, dual DigiCert RFC 3161 (`.tsr`, verified via `openssl ts -reply`) & Bitcoin OpenTimestamps (`.ots`), SLSA `actions/attest-build-provenance@v2`, and Software Heritage SWHID archival. |
